# SILAWA
Sistem Informasi Layanan Surat Warga

Website layanan pengajuan surat pengantar secara online untuk warga.

## Fitur
- ✅ Ajukan surat secara online
- ✅ Unggah dokumen persyaratan
- ✅ Cek status pengajuan
- ✅ Hasil surat dengan tanda tangan elektronik

## Teknologi
- Frontend: HTML + CSS + JavaScript
- Backend: Supabase (Siap disambungkan)
- Hosting: Vercel
